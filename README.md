# Local AI Assistant

## Purpose

This project is a local AI assistant that will:

- Run AI models locally using Ollama
- Use a Windows PC with an RTX 4070 Ti for inference
- Use a MacBook Pro as the development machine
- Store source code in GitHub
- Include documentation for setup and development
- Eventually support document search and retrieval (RAG)

## Hardware

Development Machine:
- MacBook Pro M1 Pro
- 16 GB RAM

Inference Server:
- Intel i7-12700K
- RTX 4070 Ti
- 32 GB DDR5
